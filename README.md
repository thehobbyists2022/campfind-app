# CampFind — Find the perfect summer camp near you

CampFind is a responsive single-page application that helps parents and kids find summer camps by ZIP code and age. It displays a grid of camp cards with key details, allows filtering by type, and lets users save favorites to localStorage.

## Features
- ZIP code search and age slider to narrow down camps
- Results grid with camp cards showing name, city, type, price, rating stars, and availability dot
- Expandable card details with sessions list and contact info
- Heart toggle to save favorite camps, persisted in localStorage
- Filter camps by type (Day/Overnight)

## How to Use
Open `index.html` in any browser, or serve with:
```
python3 -m http.server 8080 --directory .
```
